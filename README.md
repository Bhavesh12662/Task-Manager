# Task Manager

A simple and responsive Task Manager built using HTML, Tailwind CSS, and JavaScript.

The application allows users to create, edit, complete, and delete tasks. Tasks are stored in the browser using Local Storage, so they remain available after refreshing the page.

## ✨ Features

- Add new tasks
- Edit existing tasks
- Delete individual tasks
- Mark tasks as completed
- Unmark completed tasks
- Display total tasks
- Display pending tasks
- Display completed tasks
- Clear all tasks
- Prevent empty tasks
- Add tasks using the Enter key
- Save tasks using Local Storage
- Tasks remain after browser refresh
- Responsive design

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Browser Local Storage
